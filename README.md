# Code Droid

Android-приложение: универсальный AI-чат и автономная агентная среда разработки.

Всё работает локально на устройстве. Приложение обращается к LLM-провайдерам напрямую
(OpenAI, OpenRouter, Groq, DeepSeek, Anthropic, Gemini и OpenAI-совместимые серверы) по вашему
API-ключу. Собственный сервер не требуется.

## Статус

Этап 1 (MVP-чат) реализован: OpenAI-совместимый провайдер с потоковой
генерацией (SSE), ввод и проверка API-ключа, экран чата со стримингом,
отменой генерации и обработкой ошибок на русском языке.
Ключ хранится в SharedPreferences (шифрование через Android Keystore — Этап 2).
Следующий шаг — Этап 2: Room и история, несколько сессий, выбор модели.

## Модули

| Модуль | Назначение |
---|---|
| `app` | Точка входа, сборка |
| `core:model` | Доменные модели (чистый Kotlin) |
| `core:data` | Room, репозитории (Этап 2) |
| `core:llm` | Провайдеры, стриминг (OpenAI-совместимый API) |
| `core:agent` | Цикл агента, инструменты (Этап 3+) |
| `core:workspace` | Безопасная работа с файлами |
| `core:security` | Шифрование секретов (Этап 2) |
| `core:ui` | Тема, общие компоненты |
| `feature:*` | Экраны: chat, onboarding, settings, agent, workspace |

## Сборка

Требуется JDK 17 и Android SDK (API 37).

```bash
./gradlew :app:assembleDebug
```

CI (GitHub Actions) собирает debug APK на каждый пуш.
